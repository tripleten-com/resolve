You can upload files to any page in Quillstack by dragging them into the editor or using the attachment button. Each plan includes a different amount of storage per workspace, and every plan limits the size of a single uploaded file to 100 MB.

## Before you start

Check your current storage usage under Settings > Workspace > Storage. This shows how much of your plan's storage limit you have used and which pages contain the largest files. If you are close to your limit, consider deleting unused attachments or upgrading your plan.

Files you upload are stored in the workspace where you upload them. Storage limits apply per workspace, so if you have multiple workspaces on the same account, each one has its own separate storage allowance.

## Storage limits by plan

| Plan       | Storage per workspace | Max file size |
|------------|-----------------------|---------------|
| Free       | 500 MB                | 100 MB        |
| Team       | 50 GB                 | 100 MB        |
| Business   | 500 GB                | 100 MB        |

Every plan enforces the same 100 MB limit on individual file uploads. If you need to attach a file larger than 100 MB, split it into smaller parts or host it externally and link to it from your page.

## Steps

1. Open the page where you want to add a file.
2. Click the **+** button in the editor or drag the file directly into the page content.
3. Select **Upload file** and choose the file from your computer.
4. Wait for the upload to complete. A progress bar appears while the file is uploading.
5. Once uploaded, the file appears inline on the page and can be downloaded by anyone with access to the page.

To remove a file, click on it in the page editor and press Delete or Backspace. Deleting a file from a page frees up storage immediately, but files in deleted pages still count toward your storage limit until the page is permanently deleted from Trash after 30 days.

## Troubleshooting

**My upload fails with "File too large."** The file exceeds the 100 MB limit. Compress the file, split it into smaller parts, or upload it to an external service and link to it instead.

**I am at my storage limit and cannot upload more files.** Delete unused attachments from pages or delete entire pages that contain large files. Go to Settings > Workspace > Storage to see which pages use the most storage. If you still need more space, upgrade to a plan with a higher storage limit.

**Files I deleted still count toward my storage.** Files in deleted pages remain in Trash for 30 days and continue to count toward your storage limit during that time. To free up storage immediately, permanently delete the page from Trash or restore the page and remove the attachments manually.

**Can I upload files through the API?** Yes. Use the POST /v2/attachments endpoint with a multipart/form-data request. The same 100 MB file size limit applies to API uploads. See the API documentation at https://api.quillstack.com/v2/docs for details.
