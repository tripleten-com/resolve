You can import pages, databases, and attachments from Notion into a Quillstack workspace. The import converts Notion pages to Quillstack pages and preserves your content structure, including nested pages and inline attachments. Quillstack supports importing from Notion's HTML or Markdown export formats, and the archive you upload may be at most 2 GB.

## Before you start

Export your content from Notion before starting the import. In Notion, go to Settings & members > Settings > Export content, choose HTML or Markdown format, and download the .zip file. Do not unzip the archive. You need Admin or Owner permissions in your Quillstack workspace to start an import, and only one import can run per workspace at a time.

## Steps

1. In Quillstack, go to **Settings > Import**.
2. Click **Import from Notion**.
3. Click **Choose file** and select the .zip archive you downloaded from Notion. The file size must be 2 GB or less.
4. Select the workspace where you want to import the content.
5. Choose whether to import into the root of the workspace or into a specific parent page. If you select a parent page, all imported pages become children of that page.
6. Click **Start import**.

The import runs in the background and can take up to several hours depending on the size of your archive. You receive an email when the import completes. You can continue working in Quillstack while the import runs.

## What gets imported

The Notion importer converts your content to Quillstack format:

| Notion element | Imported as |
|----------------|-------------|
| Pages | Quillstack pages |
| Nested pages | Child pages in the same hierarchy |
| Text, headings, lists | Markdown in Quillstack pages |
| Images, PDFs, other files | File attachments (subject to storage limits) |
| Databases | Quillstack pages with tables |
| Comments | Not imported |
| Page history | Not imported; only the latest version is imported |

Notion databases are converted to Quillstack pages containing Markdown tables. If you need database functionality, you can recreate the structure using Quillstack's page templates and linked databases after the import completes.

## Import limits

Only one import can run per workspace at a time. If you try to start a second import while another is in progress, you see an error. Wait for the current import to finish or cancel it under Settings > Import before starting a new one. The archive you upload may be at most 2 GB. If your Notion export is larger, split it into smaller archives by exporting individual workspaces or top-level pages separately.

File attachments imported from Notion count against your workspace's storage limit. On the Free plan, you have 500 MB per workspace; on Team, 50 GB per workspace; on Business, 500 GB per workspace. If the import would exceed your storage limit, the import pauses and you receive an email asking you to upgrade your plan or remove files to free up space.

## Check import status

To see the status of a running import:

1. Go to **Settings > Import**.
2. Under **Recent imports**, find the import you started. The status is **In progress**, **Completed**, or **Failed**.
3. If the status is **Completed**, click **View imported pages** to see the content in your workspace.

If the import failed, the error message explains what went wrong. The most common causes are an oversized archive (larger than 2 GB), insufficient storage space, or a corrupted .zip file. Fix the issue and start a new import.

## Troubleshooting

**The import failed with "Archive too large".** Your Notion export exceeds the 2 GB limit. Export smaller sections of your Notion workspace separately and run multiple imports. Each import can go into a different parent page in Quillstack to keep your content organized.

**Some images or files are missing after the import.** Check your workspace storage under Settings > Billing > Usage. If you exceeded your storage limit during the import, some attachments were skipped. Upgrade your plan to increase storage, then re-import the content.

**The import is taking longer than expected.** Large archives with many images or nested pages can take several hours to import. If the import runs for more than 24 hours without completing, contact support and include the import ID shown under Settings > Import > Recent imports.

**Notion databases imported as plain tables.** Quillstack does not have a direct equivalent to Notion databases. Imported databases become Markdown tables inside pages. You can manually recreate database-like functionality using page templates and linked pages after the import completes.

**My Notion comments did not import.** Comments and page history are not included in Notion exports, so the Quillstack importer cannot bring them over. Only the latest version of each page is imported.
