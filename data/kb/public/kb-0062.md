You can import spaces, pages, and attachments from Confluence into a Quillstack workspace. The import preserves your content hierarchy and converts Confluence pages to Quillstack pages in Markdown format. Quillstack supports importing from Confluence Cloud and Confluence Server using an XML or HTML export, and the archive you upload may be at most 2 GB.

## Before you start

Export your content from Confluence before starting the import. In Confluence, go to Space settings > Content Tools > Export, choose HTML or XML format, and download the .zip file. Do not unzip the archive. You need Admin or Owner permissions in your Quillstack workspace to start an import, and only one import can run per workspace at a time.

## Steps

1. In Quillstack, go to **Settings > Import**.
2. Click **Import from Confluence**.
3. Click **Choose file** and select the .zip archive you downloaded from Confluence. The file size must be 2 GB or less.
4. Select the workspace where you want to import the content.
5. Choose whether to import into the root of the workspace or into a specific parent page. If you select a parent page, all imported pages become children of that page.
6. Click **Start import**.

The import runs in the background and can take up to several hours depending on the size of your archive. You receive an email when the import completes. You can continue working in Quillstack while the import runs.

## What gets imported

The Confluence importer converts your content to Quillstack format:

| Confluence element | Imported as |
|--------------------|-------------|
| Pages | Quillstack pages |
| Child pages | Child pages in the same hierarchy |
| Text, headings, lists | Markdown in Quillstack pages |
| Images, PDFs, other files | File attachments (subject to storage limits) |
| Tables | Markdown tables |
| Macros | Converted to text or removed if unsupported |
| Comments | Not imported |
| Page history | Not imported; only the latest version is imported |

Confluence macros are converted where possible. For example, code blocks and tables of contents are preserved. Macros without a Quillstack equivalent are removed, and their content may appear as plain text or be omitted entirely. Review imported pages after the import completes to check for missing content.

## Import limits

Only one import can run per workspace at a time. If you try to start a second import while another is in progress, you see an error. Wait for the current import to finish or cancel it under Settings > Import before starting a new one. The archive you upload may be at most 2 GB. If your Confluence export is larger, export individual spaces separately and run multiple imports.

File attachments imported from Confluence count against your workspace's storage limit. On the Free plan, you have 500 MB per workspace; on Team, 50 GB per workspace; on Business, 500 GB per workspace. If the import would exceed your storage limit, the import pauses and you receive an email asking you to upgrade your plan or remove files to free up space.

## Check import status

To see the status of a running import:

1. Go to **Settings > Import**.
2. Under **Recent imports**, find the import you started. The status is **In progress**, **Completed**, or **Failed**.
3. If the status is **Completed**, click **View imported pages** to see the content in your workspace.

If the import failed, the error message explains what went wrong. The most common causes are an oversized archive (larger than 2 GB), insufficient storage space, or a corrupted .zip file. Fix the issue and start a new import.

## Troubleshooting

**The import failed with "Archive too large".** Your Confluence export exceeds the 2 GB limit. Export smaller spaces or page trees separately and run multiple imports. Each import can go into a different parent page in Quillstack to keep your content organized.

**Some images or attachments are missing after the import.** Check your workspace storage under Settings > Billing > Usage. If you exceeded your storage limit during the import, some attachments were skipped. Upgrade your plan to increase storage, then re-import the content.

**The import is taking longer than expected.** Large archives with many attachments or deeply nested pages can take several hours to import. If the import runs for more than 24 hours without completing, contact support and include the import ID shown under Settings > Import > Recent imports.

**Confluence macros are missing or broken.** Not all Confluence macros have equivalents in Quillstack. Unsupported macros are removed during the import, and their content may not appear. Common examples are status macros, Jira issue links, and custom macros. You can manually recreate this content in Quillstack after the import completes.

**My Confluence comments did not import.** Comments and page history are not included in Confluence exports, so the Quillstack importer cannot bring them over. Only the latest version of each page is imported.

**The imported pages are in the wrong order.** The importer preserves the parent-child hierarchy from Confluence but does not guarantee the same sibling order. You can manually reorder pages in Quillstack by dragging them in the sidebar.
