Exporting your workspace creates a complete backup of all pages, projects, tasks, and attachments in a single downloadable archive. You can use exports to migrate data, comply with retention policies, or keep an offline copy of your team's work. The export process runs in the background and sends you a download link by email when it completes.

## Before you start

Only workspace Admins and Owners can start an export. Exports can take up to 24 hours to complete, depending on the size of your workspace. The download link is valid for 7 days after the export finishes, so you should download the archive promptly. If the link expires, you will need to start a new export.

Only one export can run per workspace at a time. If you start a new export while one is already in progress, the previous export is canceled and a new one begins.

## Export contents

The export archive is a single .zip file organized by content type. The structure looks like this:

| Folder | Contents | Format |
|--------|----------|--------|
| `pages/` | All pages, including nested pages | Markdown (.md) |
| `projects/` | Project metadata and task lists | JSON (.json) |
| `attachments/` | All uploaded files | Original format |
| `metadata/` | Workspace settings and member list | JSON (.json) |

Pages are exported as Markdown with front matter containing the page title, author, creation date, and last modified date. Nested pages are placed in subfolders that match your workspace structure. Projects and tasks are exported as JSON arrays with all fields, including custom fields, assignees, due dates, and completion status.

## Steps

1. Go to **Settings > Export** in the web app at app.quillstack.com.
2. Click **Start export**.
3. Confirm the export by clicking **Export workspace** in the dialog.
4. Wait for an email with the subject "Your Quillstack export is ready" to arrive at your account email address.
5. Click the download link in the email within 7 days.
6. Extract the .zip file to view your data.

The export includes only the current version of each page, not the full version history. If you need earlier versions of pages, use the page version history feature before exporting. Deleted pages in Trash are not included in the export.

## Export with the API

You can also start and download an export programmatically using the Quillstack API. This is useful for scheduled backups or integration with external systems.

```bash
curl -X POST https://api.quillstack.com/v2/exports \
  -H "Authorization: Bearer qs_live_..." \
  -H "Content-Type: application/json"
```

The API returns an export job ID. Poll the job status with `GET /exports/{job_id}` until the status field is `completed`, then download the archive from the URL in the `download_url` field. The download URL is valid for 7 days, just like the emailed link.

If the export fails, the status will be `failed` and you will see error code QS-1077. Start a new export to retry. For details on API exports, see the full guide in the related articles below.

## Limits and timing

Export jobs typically complete within a few hours for workspaces under 10 GB. Larger workspaces or workspaces with many thousands of pages and tasks may take up to 24 hours. You will receive the download email as soon as the export finishes, even if it completes in less than an hour.

The maximum size of an export archive is not limited by plan, but the underlying storage limits still apply: 500 MB per workspace on Free, 50 GB on Team, and 500 GB on Business. If your workspace is near its storage limit, the export will be correspondingly large.

## Troubleshooting

**I did not receive the download email.** Check your spam folder for messages from noreply@quillstack.com. If the email is not there after 24 hours, the export may have failed. Go to Settings > Export to see the status of your most recent export. If it shows as failed, start a new export.

**The download link says it has expired.** Links expire 7 days after the export completes. Start a new export to generate a fresh download link.

**The export is taking longer than 24 hours.** Contact support with the workspace name and the time you started the export. Include any error messages you see under Settings > Export.

**Can I export only certain projects or pages?** No, exports always include the entire workspace. To export a subset of your data, copy the relevant pages and projects to a new workspace and export that workspace.
