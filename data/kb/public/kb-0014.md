Quillstack projects offer three views—board, list, and timeline—so you can visualize and organize tasks in the way that works best for your team. Each view displays the same tasks and updates in real time, so you can switch between them without losing context or having to refresh.

## Before you start

You need at least Viewer permissions to see project views. Editors, Admins, and Owners can drag tasks between columns in board view, reorder tasks in list view, and adjust dates in timeline view. Views are available for all open projects; archived projects are read-only and show only the list view.

## Views explained

Each view is designed for a different way of working:

| View | Best for | Key features |
|------|----------|--------------|
| Board | Kanban-style workflows and status tracking | Columns represent statuses; drag tasks between columns to update status |
| List | Detailed review and bulk operations | Sortable table with all task properties; inline editing |
| Timeline | Planning and tracking deadlines | Gantt-style chart with start and due dates; drag to reschedule |

You can switch between views at any time using the view selector at the top of the project page. Your view preference is saved per project, so opening a project always shows the last view you used.

## Steps

### Switch to board view

1. Open the project from the Projects page.
2. Click the view selector at the top and choose Board.
3. Tasks appear in columns, one column per status.
4. Drag a task from one column to another to change its status.

### Switch to list view

1. Open the project and click the view selector.
2. Choose List.
3. Tasks appear in a table with columns for key, title, assignee, status, and due date.
4. Click any column header to sort by that property.
5. Click into a cell to edit it inline.

### Switch to timeline view

1. Open the project and click the view selector.
2. Choose Timeline.
3. Tasks with start or due dates appear as bars on a calendar.
4. Drag the left or right edge of a bar to adjust the start or due date.
5. Tasks without dates appear in a separate "Unscheduled" section at the bottom.

## Limits

A project can hold at most 5,000 open tasks. When you approach this limit, consider marking completed tasks as done or archiving old tasks to keep the project performant. Archived projects are read-only and can be restored by an Admin or Owner from Projects > Archived. Once restored, you can switch between views and edit tasks again.

## Troubleshooting

**Timeline view is empty.** Only tasks with a start date or due date appear in the timeline. Add dates to tasks in list view or board view, and they will appear in the timeline automatically.

**I cannot drag tasks in board view.** You need at least Editor permissions to update tasks. If you are a Viewer, you can see the board but cannot make changes.

**The project view is slow.** Projects with thousands of tasks may take a few seconds to render, especially in timeline view. Consider archiving completed tasks or splitting large projects into smaller ones.

**A task disappeared from timeline view.** If you removed the start and due dates, the task moves to the "Unscheduled" section at the bottom of the timeline. You can still see it in board or list view.
