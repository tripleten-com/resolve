If you discover a security vulnerability in Quillstack, we want to hear from you. This article explains how to report vulnerabilities responsibly, what to include in your report, and what to expect from our security team.

## Before you start

Security vulnerabilities are reported to security@quillstack.com. Quillstack acknowledges reports within 2 business days and does not run a paid bug bounty program. We ask that you do not publicly disclose the vulnerability until we have investigated and released a fix.

## Steps

1. Send an email to **security@quillstack.com** with "Security Vulnerability Report" in the subject line.
2. Include a detailed description of the vulnerability, covering what is affected (web app, API, mobile app, or infrastructure).
3. Provide step-by-step instructions to reproduce the issue, including any proof-of-concept code, screenshots, or HTTP request examples.
4. List the potential impact: what an attacker could do if they exploited the vulnerability (for example access another user's data, bypass authentication, or execute arbitrary code).
5. If you used a test account to investigate, include the workspace name and email address so we can review logs.

You will receive an automated acknowledgment within 2 business days. Our security team reviews the report and replies with an initial assessment within 5 business days.

## What to include

A good vulnerability report helps us understand and fix the issue quickly. Include the following details:

| Field | Description |
|-------|-------------|
| Affected component | Web app, API, mobile app, or infrastructure (for example DNS, email) |
| Vulnerability type | For example SQL injection, cross-site scripting (XSS), authentication bypass, or information disclosure |
| Steps to reproduce | Numbered procedure with exact URLs, request payloads, and expected versus actual behavior |
| Impact | What an attacker could access or control if they exploited this vulnerability |
| Affected plans | Whether the issue affects Free, Team, Business, or all plans |
| Test account details | Workspace name and email if you created a test account to investigate |

If the vulnerability involves API requests, include a curl command or raw HTTP request with headers and body.

## Responsible disclosure

We ask that you do not publicly disclose the vulnerability until we have investigated and released a fix. Once the fix is deployed, we will notify you and coordinate a public disclosure timeline if appropriate. Quillstack does not run a paid bug bounty program, but we recognize reporters in our security acknowledgments page if they agree to be listed.

## Out of scope

The following issues are not considered security vulnerabilities:

- Denial-of-service (DoS) attacks that require more than 10,000 requests per minute
- Social engineering attacks (for example phishing individual users)
- Reports from automated scanners without proof of exploitability
- Issues requiring physical access to a user's device
- Vulnerabilities in third-party services (for example Stripe, AWS, or Slack) that are not specific to Quillstack's integration

If you are unsure whether an issue qualifies, report it anyway. We will review it and let you know.

## Response timeline

After you report a vulnerability, the security team follows this timeline:

1. **Within 2 business days**: Automated acknowledgment that the report was received.
2. **Within 5 business days**: Initial assessment confirming whether the issue is a valid vulnerability and its severity (critical, high, medium, or low).
3. **Within 30 days**: Fix deployed to production (critical and high-severity issues are prioritized).
4. **After the fix is live**: Notification to the reporter with details of the resolution and, if applicable, coordination on public disclosure.

If the investigation takes longer than expected, we will send progress updates every 7 days.

## Encryption

If your report includes sensitive data (for example credentials or customer information discovered during testing), encrypt the email with our PGP key. The public key is available at https://quillstack.com/security/pgp-key.txt and has the fingerprint `4A7B 9C3D 2F1E 8D6A 5B4C 3E2F 1A9B 8C7D 6E5F 4A3B`.
