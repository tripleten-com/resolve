Archiving a project removes it from your active workspace without deleting any data. Archived projects are read-only, so no one can create, edit, or delete tasks, but you can view the project and its tasks at any time. If you need to resume work, an Admin or Owner can restore the project in a few clicks.

## Before you start

You need Admin or Owner permissions to archive or restore a project. Archived projects do not count toward any plan limits, and their tasks do not appear in workspace search or the global task list unless you explicitly filter for archived projects.

## When to archive a project

Archive a project when the work is complete or on hold and you do not expect to create new tasks. Common reasons include:

- The project delivered and the team has moved on.
- The project was exploratory and you decided not to continue.
- You want to reduce clutter in the active project list.
- The project reached the 5,000 open task limit and you need to start fresh.

Archiving is not the same as deleting. Archived projects stay in your workspace indefinitely and can be restored at any time.

## Steps

### Archive a project

1. Go to Projects and open the project you want to archive.
2. Click Settings > Archive project.
3. Confirm the action in the dialog.
4. The project disappears from the active project list and moves to Projects > Archived.

Once archived, the project is read-only. No one can create, edit, or delete tasks, and the project does not appear in the main project list or workspace search by default.

### Restore an archived project

1. Go to Projects > Archived.
2. Find the project you want to restore.
3. Click the three-dot menu next to the project name and select Restore.
4. The project returns to the active project list and becomes fully editable again.

Only an Admin or Owner can restore a project. After restoration, all tasks, comments, attachments, and history are intact.

## Limits

A project can hold at most 5,000 open tasks before it must be archived or have tasks marked as done. Archived projects are read-only and can be restored by an Admin or Owner from Projects > Archived. Once a project is archived, its tasks no longer count toward the 5,000 open task limit, so you can archive a large project and start a new one without hitting capacity.

Archiving a project does not free up workspace storage. Attachments in archived projects still count toward your plan's storage limit, which is 500 MB per workspace on Free, 50 GB per workspace on Team, and 500 GB per workspace on Business.

## Troubleshooting

**I cannot find the Archive project button.** You need Admin or Owner permissions to archive a project. Editors and Viewers cannot archive or restore projects.

**The project is archived but I need to edit a task.** Archived projects are read-only. Restore the project first, make your changes, then archive it again if needed.

**I archived a project by mistake.** Go to Projects > Archived, find the project, and click Restore. The project returns to the active list immediately.

**Can I export an archived project?** Yes. Workspace exports include both active and archived projects. Start an export from Settings > Export and the resulting .zip file will contain all projects.
