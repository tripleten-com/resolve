You can export an entire workspace programmatically using the Quillstack API. This is useful for automated backups, compliance workflows, or migrating data to another system. The export runs asynchronously, and you poll for completion before downloading the result.

## Before you start

Workspace exports can take up to 24 hours; the export is a single .zip (pages as Markdown, projects and tasks as JSON, all attachments) and the emailed download link is valid for 7 days. Only one export can run per workspace at a time. You need an API key with write permissions; Viewer-level keys cannot start exports.

## Steps

### Start an export job

Send a POST request to create an export job. The API returns a job ID immediately, and the export begins processing in the background.

```bash
curl -X POST \
     -H "Authorization: Bearer qs_live_..." \
     -H "Content-Type: application/json" \
     https://api.quillstack.com/v2/exports
```

Response:

```json
{
  "export_id": "exp_abc123xyz",
  "status": "processing",
  "created_at": "2024-08-15T14:30:00Z"
}
```

The `status` field will be `processing` until the export completes. Save the `export_id` so you can poll for completion.

### Poll for completion

Check the export status by sending a GET request with the export ID. Repeat this every 30 seconds until the status changes to `completed` or `failed`.

```bash
curl -H "Authorization: Bearer qs_live_..." \
     https://api.quillstack.com/v2/exports/exp_abc123xyz
```

Response when still processing:

```json
{
  "export_id": "exp_abc123xyz",
  "status": "processing",
  "created_at": "2024-08-15T14:30:00Z"
}
```

Response when complete:

```json
{
  "export_id": "exp_abc123xyz",
  "status": "completed",
  "created_at": "2024-08-15T14:30:00Z",
  "completed_at": "2024-08-15T15:12:00Z",
  "download_url": "https://exports.quillstack.com/...",
  "expires_at": "2024-08-22T15:12:00Z"
}
```

The `download_url` is a signed URL that expires after 7 days. Download the .zip file from this URL before it expires.

### Download the export

Use the `download_url` to retrieve the .zip archive. This URL does not require an Authorization header; it is pre-signed and temporary.

```bash
curl -o workspace-export.zip \
     "https://exports.quillstack.com/..."
```

The archive contains pages as Markdown files, projects and tasks as JSON, and all attachments in their original formats.

## Troubleshooting

**The export failed with QS-1077.** Error QS-1077 means an export job failed and a new export must be started. This can happen if the workspace is extremely large or if there was a transient error during processing. Wait 10 minutes and start a new export. If the issue persists, contact support with the `export_id`.

**Can I start multiple exports at once?** No. Only one export can run per workspace at a time. If you try to start a second export while one is processing, the API returns error QS-1015. Wait for the first export to complete or fail before starting another.

**The download URL expired.** Download URLs are valid for 7 days after the export completes. If the URL expired, start a new export job. Quillstack does not store completed exports indefinitely.

**How long does an export take?** Most workspaces export in under an hour, but large workspaces with many attachments can take up to 24 hours. The API does not provide a progress percentage; poll the status endpoint every 30 seconds until the job completes.
