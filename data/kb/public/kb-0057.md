The Slack integration sends notifications from Quillstack directly to your Slack workspace, so your team sees updates about pages, tasks, and projects where they already communicate. Only workspace Admins and Owners can install and configure the integration. Once connected, you can choose up to 20 Slack channels to receive notifications.

## Before you start

You need Admin or Owner permissions in your Quillstack workspace and the ability to install apps in your Slack workspace. If you do not have Slack admin rights, ask your Slack workspace admin to approve the Quillstack app. The integration works on all Quillstack plans.

## Steps

1. In Quillstack, go to **Settings > Integrations > Slack**.
2. Click **Connect to Slack**.
3. You are redirected to Slack. Review the permissions Quillstack requests and click **Allow**.
4. You return to Quillstack and see a confirmation that the integration is active.
5. Under **Default channel**, select the Slack channel where notifications are posted by default.
6. Click **Save**.

The integration is now active. Quillstack posts notifications to your default channel until you configure routing for specific events.

## How it works

When a Quillstack event occurs—such as a page being created or a task being completed—the integration posts a message to the configured Slack channel. The message includes a link back to the resource in Quillstack and the name of the person who triggered the event. You control which events are sent and where they go under Settings > Integrations > Slack > Event routing.

| Quillstack event | Example Slack message |
|------------------|----------------------|
| Page created | "Alice Wang created page: Q3 Planning" |
| Task completed | "Bob Lee completed task: DOCS-142 Update API guide" |
| Project archived | "Carol Diaz archived project: Website Redesign" |

The integration can post to at most 20 Slack channels per workspace. If you need to notify more channels, consider using webhooks or the API to build a custom integration.

## Configure the default channel

The default channel receives all notifications unless you set up event routing. You can change the default channel at any time:

1. Go to **Settings > Integrations > Slack**.
2. Under **Default channel**, select a new channel from the dropdown.
3. Click **Save**.

You can also set the default channel using the `slack.default_channel` configuration key. The value is the Slack channel name, including the hash symbol:

```
slack.default_channel = #general
```

This setting is useful if you manage workspace configuration as code or need to script the integration setup.

## Disconnect the integration

If you no longer want Quillstack to post to Slack, you can disconnect the integration:

1. Go to **Settings > Integrations > Slack**.
2. Click **Disconnect**.
3. Confirm by clicking **Disconnect** again.

All event routing rules are deleted and Quillstack stops posting to your Slack workspace immediately. You can reconnect at any time by following the steps above.

## Troubleshooting

**I do not see the Connect to Slack button.** Only workspace Admins and Owners can install integrations. Check your role under Settings > Members. If you are an Editor or Viewer, ask an Admin or Owner to install the integration.

**Slack says the app is not approved.** Your Slack workspace requires admin approval before new apps can be installed. Request approval from your Slack admin and include a link to this article. Once approved, return to Settings > Integrations > Slack and try again.

**I connected Slack but no messages appear.** The integration posts notifications only for events you have configured. After connecting, go to Settings > Integrations > Slack > Event routing and choose which events trigger messages. Until you set up routing, only the default channel receives notifications for all events.

**I reached the 20-channel limit.** If you need to notify more than 20 channels, remove channels you no longer need under Event routing or use the Quillstack API with webhooks to build a custom notification system.
