Page templates let you create reusable structures for common page types, and databases turn collections of pages into structured records you can filter, sort, and view as tables or boards. Both features help you organize information consistently across your workspace.

## Before you start

Templates and databases are available on every Quillstack plan. You can create as many templates and databases as you need, subject to your plan's storage limits. Each database is a special type of page that contains links to other pages, and those pages count toward your workspace's file storage allowance if they include attachments.

Templates are saved at the workspace level and can be used by any member with Editor permissions or higher. Viewers cannot create pages from templates or add records to databases, but they can view both.

## Steps

### Create a page template

1. Create a new page and add the content structure you want to reuse, such as headings, tables, or placeholder text.
2. Click the **•••** menu in the top-right corner of the page and select **Save as template**.
3. Give the template a name and choose whether to make it available workspace-wide or keep it private.
4. To use the template, click **New page** and select your template from the list.

Templates do not sync with pages created from them. If you edit a template, pages created earlier from that template do not change.

### Create a database

1. Create a new page and click **Insert** > **Database** in the editor.
2. Choose a database type: **Table** (rows and columns), **Board** (cards in columns), or **List** (simple rows).
3. Add properties to define the structure, such as text, date, select, or file fields.
4. Add records by clicking **New** in the database view or by linking existing pages.

Each record in a database is a page, so you can open it, edit the content, and add attachments just like any other page. Changes to a record appear in the database view immediately.

## Storage and limits

| Plan       | Storage per workspace | Max file size |
|------------|-----------------------|---------------|
| Free       | 500 MB                | 100 MB        |
| Team       | 50 GB                 | 100 MB        |
| Business   | 500 GB                | 100 MB        |

Database records that include file attachments count toward your workspace's storage limit. Large databases with many attached files can use significant storage, so monitor your usage under Settings > Workspace > Storage.

## Troubleshooting

**I cannot create a page from a template.** You need Editor, Admin, or Owner permissions to create pages. Viewers can see templates but cannot use them to create new pages.

**My database view is slow.** Databases with thousands of records or many file attachments can take longer to load. Consider archiving old records, splitting the database into smaller databases, or removing large attachments from records you do not need to view frequently.

**Can I share a database with a public link?** Yes, if your workspace is on the Team or Business plan. Open the database page, click Share, and toggle on "Anyone with the link." Public visitors see the database in read-only mode and cannot add or edit records.

**Templates I created do not appear for other members.** Make sure you saved the template as workspace-wide rather than private. Edit the template, click the **•••** menu, and select **Template settings** to change the visibility.
