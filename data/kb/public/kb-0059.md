The GitHub integration automatically links pull requests to Quillstack tasks when the PR title or branch name contains a task key. This keeps your code and project tracking in sync without manual updates. Once connected, every linked PR appears in the task's activity feed, and the task status updates when the PR is merged.

## Before you start

You need Admin or Owner permissions in your Quillstack workspace to install the GitHub integration. You also need admin access to the GitHub organization or repository where you want to install the Quillstack GitHub App. The integration works on all Quillstack plans.

## Steps

1. In Quillstack, go to **Settings > Integrations > GitHub**.
2. Click **Connect to GitHub**.
3. You are redirected to GitHub. Select the organization or personal account where you want to install the app.
4. Choose whether to grant access to all repositories or only specific repositories.
5. Click **Install**.
6. You return to Quillstack and see a confirmation that the integration is active.

The integration is now listening for pull requests in your selected repositories. It links PRs to tasks automatically based on the task key in the PR title or branch name.

## How task linking works

A task key has the form `PROJECTKEY-NUMBER`, where the project key is the short code you assigned when you created the project. For example, if your project key is `DOCS`, task keys look like `DOCS-1`, `DOCS-142`, `DOCS-999`. When you create a pull request, include the task key in the PR title or branch name:

```
PR title: "Add API pagination guide (DOCS-142)"
Branch name: "feature/DOCS-142-api-pagination"
```

The integration scans new and updated pull requests every few minutes. When it finds a task key, it posts a comment to the task in Quillstack with a link to the PR and the PR status. If the PR is merged, the integration also posts an update to the task's activity feed.

| Task key location | Example | Linked? |
|-------------------|---------|---------|
| PR title | `Fix login bug (DOCS-142)` | Yes |
| Branch name | `fix/DOCS-142-login` | Yes |
| PR description | `Fixes issue DOCS-142` | No |
| Commit message | `DOCS-142: Fix login` | No |

Only the PR title and branch name are checked. Task keys in the PR description, commit messages, or comments are ignored.

## Multiple repositories

If you installed the GitHub App for all repositories in your organization, every repository can link PRs to Quillstack tasks. If you chose specific repositories, only those repositories are connected. You can change repository access at any time:

1. Go to **Settings > Integrations > GitHub**.
2. Click **Manage repositories**.
3. You are redirected to GitHub, where you can add or remove repositories.
4. Click **Save**.

Changes take effect immediately. PRs in newly added repositories are scanned on the next sync, which runs every 5 minutes.

## Disconnect the integration

To stop linking GitHub pull requests to Quillstack tasks:

1. Go to **Settings > Integrations > GitHub**.
2. Click **Disconnect**.
3. Confirm by clicking **Disconnect** again.

Past PR links remain in task activity feeds, but new PRs are not scanned. You can reconnect at any time by following the steps above.

## Troubleshooting

**I do not see the Connect to GitHub button.** Only workspace Admins and Owners can install integrations. Check your role under Settings > Members. If you are an Editor or Viewer, ask an Admin or Owner to install the integration.

**The integration is connected but PRs are not linking.** Verify that the PR title or branch name contains the exact task key, including the project key and hyphen. For example, `DOCS-142` works but `DOCS 142` or `docs-142` does not. Task keys are case-sensitive. If the task key is correct, check that the repository is included in the integration's repository access.

**GitHub says the app installation failed.** You need admin permissions for the GitHub organization or repository. If you do not have admin access, ask a GitHub admin to install the Quillstack GitHub App and then return to Settings > Integrations > GitHub in Quillstack to complete the connection.

**A PR linked to the wrong task.** If a PR title or branch name contains multiple task keys, the integration links the PR to the first task key it finds. Edit the PR title or branch name to include only the correct task key, and the link updates on the next sync.
