Workspace exports usually complete within a few hours, but large workspaces with many attachments can take up to 24 hours to process. If your export is taking longer than expected or you received error QS-1077, you need to start a new export job. This article explains what causes slow or failed exports and how to resolve them.

## Before you start

Exports are available to workspace Admins and Owners only. The export includes all pages as Markdown files, projects and tasks as JSON, and all file attachments in their original formats. The complete export is packaged as a single .zip file, and you receive an email with a download link when it is ready. That link remains valid for 7 days, after which you need to start a new export to download again.

Only one export can run per workspace at a time. If you start a new export while one is already in progress, the earlier job is canceled.

## What slows down exports

Export speed depends on the size of your workspace. The main factors are:

| Factor | Impact |
|--------|--------|
| Number of pages | Each page is converted to Markdown and included |
| Number of tasks | All tasks and their metadata are exported as JSON |
| File attachments | Every attachment is copied into the archive |
| Total storage used | Larger workspaces take longer to package |

Workspaces using more than 10 GB of storage or containing more than 5,000 pages typically take 6 to 12 hours. Workspaces approaching the storage limits on Team (50 GB) or Business (500 GB) can take the full 24 hours. The export job runs in the background, so you can continue working in Quillstack while it processes.

## Error QS-1077: export failed

Error QS-1077 means an export job encountered a problem and could not complete. The most common causes are:

- **Corrupted attachment**: One file in your workspace could not be read or copied.
- **Timeout**: The export took longer than the maximum allowed processing time.
- **Server issue**: A temporary infrastructure problem interrupted the job.

When you receive QS-1077, the failed export is discarded and you must start a new one. There is no way to resume or retry a failed export automatically.

## Steps

### Start a new export

1. Sign in at app.quillstack.com as an Admin or Owner.
2. Go to Settings > Export.
3. Click **Start export**.
4. Wait for the confirmation message that the export has started.
5. Check your email for the download link; exports usually arrive within 2 to 6 hours, but can take up to 24 hours.

### If the export fails again

1. Go to Settings > Workspaces and note how much storage your workspace is using.
2. If you are near your plan's storage limit, delete large attachments you no longer need or archive old projects.
3. Wait 10 minutes, then start a new export.
4. If the export fails a second time with QS-1077, contact support and include the approximate time you started each export so the team can check server logs.

## Troubleshooting

**My export is still processing after 24 hours**

If you have not received the download email after 24 hours, the export has likely failed without sending an error notification. Start a new export from Settings > Export. If the new export also exceeds 24 hours, contact support.

**The download link expired before I could download the file**

The link is valid for 7 days. If it has expired, start a new export. There is no way to extend or regenerate the link for an old export.

**Can I export only part of my workspace?**

No. Exports always include the entire workspace: all pages, all projects and tasks, and all attachments. If you need only specific pages, copy them to a new workspace and export that workspace instead.

**The .zip file is corrupted or will not open**

Try downloading the file again using a different browser or device. If the problem persists, start a new export. If the new export also produces a corrupted file, contact support with the file size and the error message from your unzip tool.
