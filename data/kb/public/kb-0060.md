If your GitHub pull requests are not linking to Quillstack tasks, the most common cause is a missing or incorrect task key in the PR title or branch name. The GitHub integration scans for task keys in the form `PROJECTKEY-NUMBER` and links the PR only when it finds an exact match. This article walks through how to verify the task key format and troubleshoot other linking issues.

## Before you start

Confirm that the GitHub integration is connected and that the repository containing your pull requests is included in the integration's repository access. Go to Settings > Integrations > GitHub and check the status. If the integration is not connected, follow the steps in the article linked below to install it.

## Steps

1. Open the pull request in GitHub and check the PR title and branch name.
2. Verify that the task key appears in either the title or the branch name, using the exact format `PROJECTKEY-NUMBER`. For example, `DOCS-142` is valid but `docs-142`, `DOCS 142`, or `#DOCS-142` are not.
3. Confirm that the project key matches the key assigned to the project in Quillstack. Go to **Projects** in Quillstack and check the key shown next to the project name.
4. If the task key is correct, check that the task exists and is not deleted. Search for the task key in Quillstack or visit the task directly by appending the key to your workspace URL: `app.quillstack.com/workspaces/YOUR_WORKSPACE/tasks/PROJECTKEY-NUMBER`.
5. Wait 5 minutes for the next integration sync, then refresh the task page in Quillstack to see if the PR link appears.

If the PR still does not link after following these steps, proceed to the troubleshooting section below.

## Common task key format errors

The integration only recognizes task keys that match the format exactly. Here are the most frequent mistakes:

| Incorrect format | Correct format | Why it fails |
|------------------|----------------|--------------|
| `docs-142` | `DOCS-142` | Project key must be uppercase |
| `DOCS 142` | `DOCS-142` | Missing hyphen between key and number |
| `[DOCS-142]` | `DOCS-142` | Brackets are not part of the key |
| `Fix DOCS-142` | `DOCS-142 Fix` | Key must appear at the start or surrounded by whitespace or punctuation |

To avoid errors, copy the task key directly from the task page in Quillstack and paste it into your PR title or branch name. The task key is shown in the top-left corner of every task.

## Check repository access

If the task key is correct but the PR is not linking, verify that the GitHub integration has access to the repository:

1. Go to **Settings > Integrations > GitHub** in Quillstack.
2. Click **Manage repositories**.
3. You are redirected to GitHub. Check that the repository is listed under **Repository access**.
4. If the repository is missing, select **All repositories** or add the repository to the list of selected repositories.
5. Click **Save** and return to Quillstack.

Changes take effect within 5 minutes. Open the task page in Quillstack and refresh to see if the PR link appears.

## Verify the task exists

If the task key in your PR title or branch name does not match any task in Quillstack, the integration cannot create a link. This happens if:

- The task was deleted or archived.
- The task key is from a different workspace.
- The project key was changed after the task was created.

Search for the task key in Quillstack to confirm it exists. If you cannot find the task, check the project's archived tasks or ask a workspace Admin if the project key was renamed.

## Troubleshooting

**The integration was connected recently but old PRs are not linking.** The integration only scans PRs opened or updated after the connection was made. To link an older PR, edit the PR title or branch name to add the task key, then wait 5 minutes for the next sync.

**I see the task key in the PR description but it did not link.** The integration only checks the PR title and branch name. Task keys in the PR description, commit messages, or comments are ignored. Move the task key to the PR title or branch name.

**The PR linked to the wrong task.** If your PR title or branch name contains multiple task keys, the integration links the PR to the first task key it finds. Edit the PR title or branch name to include only the correct task key. The link updates on the next sync.

**The PR was merged but the task status did not update.** The integration posts a comment to the task's activity feed when a linked PR is merged, but it does not automatically change the task status. If you want task statuses to update when PRs merge, you can set up a webhook to listen for `task.updated` events and use the API to change the status based on the PR state.

**I disconnected and reconnected the integration and now no PRs link.** Disconnecting the integration removes its access to GitHub but does not delete past PR links in Quillstack. After reconnecting, only new or updated PRs are scanned. To re-link an old PR, edit its title or branch name to trigger a new scan.
